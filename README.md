# 🚗 Car Dealership Inventory Management System

A full-stack web application for managing a car dealership's vehicle inventory.

The application allows dealership users to add, view, update, delete, search, filter, and mark vehicles as sold. It also provides a dashboard showing inventory statistics and total inventory value.

---

## 📌 Features

- Add new vehicles
- View all vehicles
- View vehicle inventory
- Edit vehicle details
- Update vehicle information
- Delete vehicles
- Mark vehicles as sold
- Search vehicles by brand or model
- Filter vehicles by fuel type
- Filter vehicles by availability
- Dashboard with inventory statistics
- Display total vehicles
- Display available vehicles
- Display sold vehicles
- Calculate total inventory value
- Success and error messages
- Form validation
